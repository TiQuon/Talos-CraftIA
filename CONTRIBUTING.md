# Contributing

External contributions are **not accepted yet**.

When contributions open:

1. You must accept the Contributor License Agreement in CLA.md
   (explicit signature or CLA bot on the hosting platform).
2. Code must be ASCII in executable sources.
3. Every source file needs the SPDX header for its license class.
4. Do not add GPL/AGPL dependencies to the engine or orchestrator.
5. Do not commit secrets, API keys, Minecraft jars, or textures.

Until then, please open an issue for discussion instead of a pull request.
