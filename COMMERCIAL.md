# Commercial use

Talos CraftIA is free for noncommercial purposes under PolyForm Noncommercial
1.0.0 (software) and CC-BY-NC-4.0 (data/docs). Any commercial use needs a
separate written license from the copyright owner (TiQuon_).

## What counts as commercial (default reading)

If you get money, directly or indirectly, from a product that includes or uses
this software, treat it as commercial and ask for a license. Examples:

- Selling the software, a fork, a hosted service, or a paid plugin
- Servers with paid ranks, ads, or donation perks tied to this software
- Monetized videos or streams that redistribute the software itself as a product
- Modpacks in reward programs that ship this software
- Patreon / paid Discord access whose main deliverable is this software

Gray areas in the Minecraft community exist. When unsure, ask before shipping.

## User-generated structures

The software license does not claim copyright over structures a user generates
for themselves. Style packs and components redistributed as packs remain under
CC-BY-NC-4.0. Using this software to produce content for paid products is still
commercial use of the software.
